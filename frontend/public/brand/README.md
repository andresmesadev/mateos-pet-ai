# Huella Nex — recursos de identidad

Símbolo elegido por Andrés: opción 02, «Vínculo», con perfiles de perro y gato.
Nombre visible: **Huella Nex**, sin «o» al final y con espacio entre palabras.

El PNG conserva transparencia. El nombre se presenta como texto accesible
mediante el componente compartido `ProductBrand`; no se recorta de la lámina
de presentación. El descriptor es «Gestión para negocios de mascotas» y
abarca veterinarias, pet shops y peluquerías caninas y felinas.

La marca del producto es independiente del nombre y los datos de cada negocio.
Los identificadores heredados del despliegue y los registros históricos se
conservan por compatibilidad.
