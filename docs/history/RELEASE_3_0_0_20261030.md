## Alcance

Se publica el lote revisado de Huella Nex, software común para veterinarias,
peluquerías caninas/felinas y pet shops. Mateos Pet conserva su identidad como
primer establecimiento, sus registros reales y configuración. Los nombres
técnicos heredados se conservan por compatibilidad.

Incluye marca e iconos, incorporación guiada por módulos, configuración y
contactos propios en comprobantes/PDF, estado del servicio, recuperación y
salida asistida, correcciones comerciales y preparación por tenant de rutas
WhatsApp y cupos de IA. Se conserva el control de activación: la publicación
no habilita proveedores comerciales, modifica credenciales ni da aprobación
a Meta en nombre del negocio.

La versión **3.0.0** se declara en backend y frontend y sus locks. El endpoint
de salud usa el manifiesto backend. El salto de versión autorizado identifica
esta publicación del producto; no supone cerrar estabilidad, recuperación
independiente o aceptación externa pendientes.

## Migraciones y recuperación

Hay dos migraciones aditivas de proveedores: conexiones/cupos y auditoría.
Se ensayaron desde PostgreSQL vacío, sin diferencia respecto del esquema.
No se aprovisionan credenciales, cupos, mensajes o cobros reales por migrarlas.
Se requiere un respaldo cifrado comprobado antes de aplicarlas en la VPS.

Se conservarán commit e imágenes anteriores para volver a la aplicación previa
si hay regresión. Al ser tablas/columnas añadidas, no se borrarán las nuevas
tablas como método de recuperación. Una restauración de datos requiere una
decisión aparte, considerando las operaciones posteriores al respaldo.
No se recreará ni borrará el volumen PostgreSQL para esta publicación.
