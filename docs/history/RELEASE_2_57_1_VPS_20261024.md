# Publicación 2.57.1 — búsqueda y base en el cobro

24/10/2026. Commit, push y despliegue autorizados por el responsable.
Preparación local terminada; CI y comprobaciones de producción pendientes.
Versión de parche: correcciones del adaptador POS sobre capacidades existentes.

## Alcance

- Un único buscador para productos y servicios. Cada nuevo cobro abre en Todos;
  los filtros mantienen la consulta y comparten resultados, escaneo y selección.
  El catálogo permanece cerrado hasta buscar o pulsar Ver catálogo.
- Dinero base visible encima del total a cobrar, con confirmación/actualización
  usando el registro y permisos administrativos ya existentes de Caja. La base
  no se suma a la venta. Enter en ese campo no confirma el pago.
- Sin cambios de schema, migraciones, reglas de precio, stock ni comisiones.
  Se conserva el cobro de vacunación por artículos de 2.57.0.

Diseños: [buscador](../architecture/pos-unified-catalog-search-20261024.md) y
[base de caja](../architecture/pos-checkout-cash-opening-20261024.md).

## Verificación previa

32 pruebas locales de buscador, base, carrito y borradores aprobadas; lint y
build/TypeScript correctos, 32 rutas. Se revisó el uso de proxy autenticado,
permisos existentes y separación entre guardar la base y confirmar el cobro.
La revisión visual en navegador está pendiente porque su uso está deshabilitado
en esta sesión; los renders de componentes son pruebas aisladas, no una prueba
visual completa. No se alteraron datos reales para ensayar.

Revertir ante salud caída, errores persistentes o bloqueo nuevo del cobro,
usando imágenes previas y evidencia privada; no restaurar una base antigua sobre
