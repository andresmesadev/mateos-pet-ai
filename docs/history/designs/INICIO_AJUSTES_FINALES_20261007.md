# Inicio — ajustes finales propuestos

> Archivo de diseño concluido. Conserva el diagnóstico y la propuesta de su fecha; no es una lista de trabajo pendiente. Implementación y límites de comprobación: [informe de cierre](../INICIO_AJUSTES_FINALES_20261007.md). Estado de publicación: [estado actual](../../ESTADO_ACTUAL.md).

## Revisión del estado actual

Inicio ya reúne acciones rápidas, resumen operativo, pendientes, agenda compacta y resultados administrativos. Respeta permisos y módulos, conserva el establecimiento seleccionado y diferencia fallos de lectura de listas vacías.

No encontré un bloqueo nuevo en los componentes revisados. Propongo estos tres ajustes de presentación para facilitar el trabajo diario.

## 1. Ordenar los pendientes según el perfil

Hoy «Necesita atención» utiliza el mismo orden de áreas para todos. Mantendría una sola sección, con este orden preferente:

| Perfil | Primero |
| --- | --- |
| Administrador | Alertas de inventario vencido y tareas operativas pendientes; después seguimiento comercial. |
| Recepción | WhatsApp, revisión de cobros y entregas que tenga autorizadas. |
| Veterinario | Historias clínicas pendientes y después las otras tareas autorizadas. |
| Peluquero | Entregas de peluquería y después las otras tareas autorizadas. |

El cambio afecta únicamente al orden visual. No concede permisos, cambia estados ni introduce una clasificación de urgencia clínica.

## 2. Mostrar la hora de actualización

Junto a «Actualizar Inicio», mostrar «Consultado a las 10:35 a. m.», con hora de Colombia. Si alguna fuente falla, indicar «Actualización parcial» y conservar la explicación de la fuente afectada.

Esto permite saber cuándo se consultaron los datos. No implicaría actualización en tiempo real ni añadiría consultas automáticas frecuentes.

## 3. Reducir la longitud en móvil

Cuando haya muchos tipos de pendientes, presentar inicialmente los tres primeros y un botón «Ver otros pendientes». Al expandir, mostrar el resto en la misma sección, con sus accesos y avisos actuales.

Así la agenda queda más cerca de las acciones principales. La etiqueta contaría tipos de pendientes ocultos, no un total de pacientes, productos o seguimientos que la vista breve no conoce. Los avisos de fuentes no disponibles seguirían visibles.

## Criterio de cierre

Aplicar estos ajustes conservando botones, colores y permisos existentes. Comprobar teclado, expansión móvil, orden por perfil y actualización parcial. Después, cerrar la revisión de Inicio y continuar con la siguiente área, salvo que aparezca un problema concreto durante el uso.
